# Azure Infrastructure as Code Portfolio (Bicep & CI/CD)

## Repository Purpose

This repository serves as a centralized portfolio for production-grade Azure administration labs and Infrastructure as Code (IaC) solutions. It demonstrates modern cloud engineering practices, including automated deployments, modular architecture, and version control workflows aligned with enterprise standards.

## Core Engineering Patterns

* Reusable Bicep Modules: Modular, decoupled blueprints for core Azure resources to ensure consistency and reusability across environments.
* Automated CI/CD Pipelines: Continuous integration workflows built with GitHub Actions to validate and preview infrastructure changes using automated dry-run analysis.
* Environment Separation: Structured configurations designed to isolate workloads and manage infrastructure lifecycles safely.

## Repository Structure Pattern

This repository is organized around modular templates and automated pipelines, designed to scale dynamically as additional Azure administration projects are integrated.
